# TASKFORGE

TASKFORGE — консольный менеджер задач на Python.

## Возможности

- Создание задач
- Просмотр задач
- Запуск задач по ID
- Проверка уникальности ID
- Выполнение Windows-команд
- Использование `subprocess`
- Использование многопоточности (`threading`)
- Получение результата выполнения задачи
- Отображение статуса задачи
- Обработка ошибок выполнения команд
